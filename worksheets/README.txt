START
1. Keep the example files unchanged for reference.
2. Open the relevant blank worksheet in your spreadsheet application. Import identifiers such as SKUs as text if you need to preserve leading zeroes.
3. Replace or add rows with your own information. Calculate and review amounts and times yourself; the filled examples contain typed results, not formulas.
4. Save a separate file for each review, project, collection or event. Review private details before sharing.

CATALOG REVIEW
This is a review checklist, NOT a Shopify product import template. Do not upload it, or any fictional example in this pack, into your store. It helps record questions about a current export and proposed update: prices, identifiers, blank fields and variant matches. It does not validate an import, inspect a live store or establish the effect of any Shopify setting. A blank or unresolved answer means review is still needed.

The fictional example reflects our sample report: a price moves from 24.00 to 30.00 (25%); SKU 000101 becomes 000101-new; a vendor and another price become blank; one option combination is absent; one variant is unmatched. Absence alone does not establish deletion. Zero reported errors does not mean no issues remain.

SCOPE CHANGES
Estimated amount = estimated minutes / 60 x your hourly rate. Round each request to the nearest currency cent, then add the line amounts. In the example, proposed work is 340.00 USD; recorded-as-approved work is 127.50 USD; the declined 255.00 USD estimate is excluded from those totals. Statuses are manual notes, not authenticated client approvals. Taxes and fees are excluded. This worksheet is not a contract, invoice or billing service.

WHOLESALE COLLECTION
Line subtotal = order quantity x wholesale unit price. Review minimum quantities and case multiples independently. The example has 6 cups x 12.50 plus 4 bowls x 18.00 = 147.00 USD before tax and shipping. No vases are selected. This worksheet does not check stock, place orders or accept payment. It is a manual companion, not a promised import format for any app or store. Product photos are not embedded in these CSV files. Currency labels do not convert values.

RUN OF SHOW
Each next planned start = prior planned start + planned duration + buffer. Each next projected start uses a measured actual duration where entered and planned duration where the actual is blank, plus the same buffer. Blank actual and zero actual are different. The fictional event plans to finish at 20:02 and projects 20:05, three minutes later. These are manual wall-clock calculations, not live countdowns or time-zone/daylight-saving conversions. If a schedule crosses midnight, record its day/date explicitly in your own copy. Keep current crew versions aligned.
